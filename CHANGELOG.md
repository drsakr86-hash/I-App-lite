# Changelog

## Unreleased
- Rx guide 2: the guide is now editable, printable and part of the patient cycle. Doctors/admin (`rx_guide.write`) can edit any card, add the clinic's own cards, hide or delete them and restore the original; changes are stored as a synced overlay (`iapp_rx_guide`, no migration) so the original text is never lost and every change is audited. Each card (or the filtered results) prints on an A4 sheet with the clinic header. New «📖 من الدليل» picker in the prescription medicines step (ticks recognised drugs, shows warnings read-only, nothing auto-saved) and in the exam treatment plan. The prescription drug dropdown is now grouped and includes the drugs extracted from the guide (drops, ointments, oral, syrups, IV; intravitreal injections excluded). Tests 1133 → 1147 plus extended render smoke. No database or deployed-function change.
- Rx guide: new More-menu tab "دليل الروشتة" (doctor and admin only, permission `rx_guide.read`) with the clinic's "Rx in a minute" reference (214 cards, 12 chapters, 68 urgent; prepared by Dr. Reem Fawzy, condensed from the Wills Eye Manual): Arabic-aware search, chapter and urgent filters, read-only (nothing is copied into a prescription). Data is a lazy chunk generated by `scripts/build-rx-guide.mjs`. Tests 1128 → 1133 plus a render smoke test in CI. No database or deployed-function change.
- Review follow-up (user decisions 2b, 3b, e2e): every native `alert()`/`confirm()` (49 calls, 20 files) now goes through `askConfirm`/`notify` (`src/modules/ui/dialogs.js`) and is rendered by the in-app `DialogHost` (back button and ESC close it; with stacked dialogs only the top one reacts to ESC/Tab); technical errors are shown as readable sentences (`src/modules/errors/friendly.js`) with the raw text kept in the error log; real-browser tests `npm run test:e2e` (`e2e/run.mjs`, playwright-core + the installed Chrome, offline, fake seeded data) added to CI. Tests 1070 → 1076.
- Full review 2026-11 (see `docs/REVIEW-2026-11.md`): back button (Android/browser) now closes the open dialog / search / More sheet / patient file and then returns to the previous tab instead of leaving the app (`src/app/back-stack.js`); one Arabic-aware search rule for every search box (alef/yaa/taa-marbuta forms, Arabic-Indic digits) in `src/modules/search/text.js`; fixed an open-patient request being ignored while the Patients tab was already open (and firing later); search results for prescriptions/appointments open the patient file; logout asks first and reports unsynced changes; 5 s polls pause while the page is hidden; vendor chunks split (update download 930 kB → ~555 kB); current tab survives reload; Ctrl/⌘+K search; Vite 6.4.3 → 6.4.6. No database or deployed-function change. Tests 1050 → 1070.
- AI scribe (Gemini): "🎙 تسجيل الكشف" card at the top of the exam form. The doctor confirms written consent, records the visit on the phone, and the new `ai-scribe` Edge Function sends the audio to Gemini (structured JSON, temperature 0) and returns a draft of the general exam fields with the sentence each value came from. Values outside the sheet's own lists (VA, IOP 10–30, selects) are dropped with a warning; diagnosis/plan only when the doctor said them. The doctor ticks rows to apply; nothing is stored until the normal save, and the exam records `aiScribe` (used, consent, model). Admin only (role re-checked server-side), audio never stored, logs carry no clinical text. Needs secrets `GEMINI_API_KEY` (paid tier) and optional `GEMINI_MODEL` (default `gemini-flash-latest`). Tests +11.
- Accounting redesign (see `docs/ACCOUNTING-FINAL-REPORT.md`): separate financial domain (charges → payments → balanced ledger → accounts), payment methods and accounts, append-only/reversal-only history, doctor settlements, cash reconciliation with period lock, financial audit trail, explicit recurring-expense generation, idempotent legacy migration with dry-run. Secretary collection records fee + amount collected now + method + account. SQL in `docs/sql/accounting-core.sql` (not applied until approved; rollback included). Settings reset no longer touches expenses. Tests 702 → 740.
- Patient booking: same-day booking is allowed again (today is offered while a slot at least 10 minutes ahead remains) and slots are 10 minutes apart (was 30), inside the same clinic windows.
- Admin: pending patient booking requests now appear on the dashboard and the appointments screen with accept/reject (previously only the secretary screen read `iapp_booking_requests`). Status writes are checked, accepting twice never duplicates an appointment, and a request already handled elsewhere is reported.
